### 苹果原生 AI（Foundation Models）
- 新增 `ClipKitMac/AIProcessor.swift`：
  - `#if canImport(FoundationModels)` + `@available(macOS 26.0,*)` 走真实现（`LanguageModelSession` + `respond(to:)`），当前 14 SDK 自动编译但走 `#else`。
  - 真实现：单一 prompt 让模型判断意图 → 返回 JSON `{kind, language, output}`：formatJSON / translate（语言与系统不一致）/ summarize（>200 字符）/ none。
  - 降级实现：无 Apple Intelligence 时仅 JSON 美化（`JSONSerialization` 2 空格缩进），翻译/摘要返回 nil。
  - `isAvailable` 用 `SystemLanguageModel.default.isAvailable` 判定。
- 接入数据流：
  - `Clip` 模型加 `aiOutput: String?` / `aiKindRaw: String?`（Optional 隐式 nil）。
  - `ClipStore.updateAI(id:output:kind:)` 写回并落盘。
  - `ClipboardViewModel`：`aiEnabled` 开关（UserDefaults 键 `clipkit.aiEnabled`）；`.clipKitNewClip` 观察者收到新剪贴板后调 `enrichWithAI`，仅对 text/richText/code 且 ≥15 字符调用；系统语言取自 `Locale.preferredLanguages.first`。
  - `ClipRow.aiRow`：卡片显示 sparkles 图标 + 标签（翻译/JSON 格式化/摘要）+ 结果文本（JSON 用等宽字体、最多 5 行）。
  - 设置页「启用 AI 增强」开关 + 不支持时的降级说明。
