- 卡片结构改为 header/content/footer 三段贴边（`clipShape` 圆角），header 不再浮在 padding 内。

## 追加：修复三个 bug（菜单栏点击/搜索/分类条）

1. **点菜单栏图标弹面板**：根因 `windowDidResignKey` 无条件隐藏，与 `togglePanel` 竞态。改为先判断失焦目标是否为状态栏窗口（`statusItem?.button?.window`），是则跳过隐藏交给 toggle 处理；`showPanel` 内 `panel.makeKeyAndOrderFront(nil)` 让面板立即成 key，并 post `.clipKitPanelDidShow` 通知。
2. **搜索被周期刷新覆盖**：0.5s 刷新循环调 `refresh()` 用全量数据覆盖结果。合并为 `reloadClips()`（应用 searchQuery + selectedFilter），`refresh()`/`search()` 都走它。
3. **分类条 + 加号新建**：新增 `ClipCategory` 模型（UserDefaults 键 `clipkit.categories` JSON 持久化），`BottomBarView` 加 `categoryBar`：剪贴板(全部)+用户分类(彩色圆点)+加号弹窗（`AddCategoryView`，名称+类型过滤）。默认种子分类「实用链接」(link/红)。选中分类写入 `viewModel.selectedFilter`。面板高度 bottom/top 200→232 给分类条腾空间。点击搜索栏任意处聚焦光标；`onReceive(.clipKitPanelDidShow)` 重新聚焦。
